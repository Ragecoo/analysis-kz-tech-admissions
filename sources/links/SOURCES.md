## Фактический приём в вузы и СУЗы

Годовые выпуски БНС охватывают 15 учебных лет, с 2011/12 по 2025/26. Для рядов технического приёма нужна колонка приёма в таблицах по специальностям. В выпусках 2025/26 она присутствует на листе `17` у вузов и `3` у ТиПО. Два файла `*_admissions_series.xls` дают общий приём и пригодны для сверки итогов и расчёта долей. Сопоставление старых и новых классификаторов и проверка непрерывности именно технического ряда выполняются при обработке.

## Гранты бакалавриата

Оригинальные PDF МНВО РК содержат списки конкурса по всем опубликованным направлениям. Группа B057 найдена во всех трёх файлах. Для проекта из них нужно извлечь записи только по техническим группам, включая B057. Исходные PDF содержат ФИО и ИКТ, которые следует исключить из аналитических выгрузок. Сведения о категории конкурса и квоте следует проверять по заголовкам разделов каждого выпуска. Код вуза следует хранить отдельно от региона проживания, наличие которого как сопоставимого поля пока не подтверждено.

### Проверка индивидуальных данных

- [Актюбинский высший политехнический колледж](https://ahpc.edu.kz/contestResults) анонсировал полные результаты конкурса 2025 года. Доступный файл с баллами, квотами и кодами специальностей подтвердить не удалось.
- [Алматинский государственный колледж связи и информационных технологий](https://agksit.kz/index.php/ru/10-novosti?layout=blog&start=40) направляет участников конкурса на городской портал для индивидуальной проверки после входа.
- В [архиве управления образования Карагандинской области](https://www.gov.kz/org/karaganda-bilim/documents/1?directions=_3800) найдены публикации по медицинским, педагогическим и творческим направлениям. Сопоставимый открытый список по техническим специальностям в проверенных публикациях не подтверждён.
- [Официальная инструкция по конкурсу ТиПО](https://www.gov.kz/situations/752/1590?lang=ru) описывает средний конкурсный балл и квоты. Для микроданных ТиПО потребуются собственные коды специальностей и отдельная обработка конкурсного балла. B057 и балл ЕНТ относятся к вузовской выборке.
