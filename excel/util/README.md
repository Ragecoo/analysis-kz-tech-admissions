# Исторические данные БНС по техническому приёму

Период выгрузки — 2011/12–2025/26, по 15 учебных лет для вузов и СУЗов. Все числа приёма извлечены из исходных таблиц БНС. Файл открывается в Excel через **Данные → Из текста/CSV** с разделителем **точка с запятой**. Столбец с кодом специальности следует импортировать как текст.

| Файл | Содержание |
|---|---|
| [admissions-by-year.csv](admissions-by-year.csv) | 30 годовых строк. Общий приём БНС, технический приём, технический приём женщин, статус и местоположение источника. |
| [technical-codes.csv](technical-codes.csv) | Строки с техническими группами и специальностями. Для каждой указаны файл, вложенная книга, лист, номер строки и правило отбора. |
| [specialty-source.csv](specialty-source.csv) | Извлечённые строки исходных таблиц со всеми кодами и доступными показателями приёма, контингента и выпуска, всего и по женщинам. Есть строки групповых итогов и детальные строки. |
| [source-tables.csv](source-tables.csv) | Реестр 30 исходных таблиц и сверка общего приёма с отдельными динамическими рядами БНС. |

## Статусы рядов

- **published_area** — взяты опубликованные итоги двух областей, ИКТ и инженерных, обрабатывающих и строительных отраслей. Для вузов это 2019/20–2025/26, для СУЗов — 2021/22–2025/26. В файле кодов эти групповые итоги и строки детализации имеют разные статусы. При суммировании использовать один уровень.
- **legacy_included** — предварительная оценка по детальным строкам старого классификатора. В СУЗах взяты старые отрасли с префиксами 06–14 с исключениями для смешанных, пограничных и сервисных специальностей. В вузах взяты детальные специальности старого технического блока с исключениями, а также вынесенные в другие группы архитектура и информационная безопасность. Это рабочие решения по историческому охвату. Полное соответствие современным областям ещё нужно проверить.
- **legacy_review** — отдельные строки, для которых граница между техническими и другими областями требует сверки. Они исключены из предварительного итога. Их приём показан в отдельном столбце реестра годовых итогов. Этот столбец показывает объём отмеченных случаев, а не полную оценку неопределённости.
- **modern_detail** — детальные строки современных технических таблиц. Имеющиеся нули сохранены. Пустое числовое поле означает, что значение недоступно или его нет в данном выпуске.

## Сверка

Национальные итоги приёма в выпусках СУЗов совпали с динамическим рядом БНС за все 15 лет. По вузам за 2011/12–2015/16 национальные итоги в таблицах по специальностям ниже общего динамического ряда на 504, 535, 793, 639 и 1 223 человека соответственно. Это различие оставлено в двух отдельных колонках. За 2019/20 вузовская таблица приёма содержит данные по направлениям, а общий итог взят из отдельного динамического ряда. У этого выпуска в выгрузке по направлениям доступны приём и приём женщин. Для остальных признаков этого года нужны отдельные листы.

Для сравнения вариантов шестилетнего прогноза пока можно использовать опубликованные современные области. Для окончательного длинного прогноза нужно проверить историческое соответствие кодов и чувствительность прогноза к переходу классификации. Предварительные исторические значения уже доступны для просмотра с пометкой статуса.

Для повторной выгрузки используется `extract.py` с библиотеками `xlrd`, `openpyxl` и доступной командой `tar`.
